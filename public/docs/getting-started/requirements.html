Requirements

Supported server and network requirements for Portivo v2.0.0.

v2.0.0Source-backed

Windows

  • 64-bit Windows 10, Windows 11 or Windows Server.
  • Administrator privileges during installation.
  • Internet access during the first installation.
  • TCP port 8766 available on the host.

Linux

  • Debian 12 or newer, or Ubuntu Server 24.04 LTS or newer.
  • 64-bit systemd-based Linux.
  • Python 3.11 or newer.
  • root or sudo access.
  • Internet access during the first installation.

Network devices

Portivo currently targets compatible ALE OmniSwitch devices with AOS 6 and AOS 8. Availability varies by model, AOS release and device capabilities. Portivo does not currently advertise Cisco, HPE, Aruba or other third-party switch support.

Management network

Do not expose Portivo directly to the public Internet. The default deployment uses HTTP and is intended for trusted management networks. Restrict TCP 8766 to the management subnets that actually require access.

Browser connectivity

The interactive terminal uses WebSockets. If a reverse proxy is used, it must forward WebSocket upgrade traffic in addition to normal HTTP requests.

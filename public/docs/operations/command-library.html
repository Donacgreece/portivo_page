Catalog scale

The current action catalog contains 149 entries across 12 categories. 133 are classified read and 16 as change.

Compatibility tiers

  • documented: direct family baseline mapping backed by the Portivo command profile.
  • orchestrated: a Portivo workflow composed from safe ALE queries.
  • model_dependent: may require model/release capability confirmation.
  • unsupported: blocked for that detected family.

Role filtering

Users see only command templates they are allowed to execute. Read-only actions require operations.read; Custom CLI remains an explicit high-trust capability.

Compatibility tiers

  • Documented: direct family baseline mapped from verified syntax.
  • Orchestrated: a safe multi-query Portivo workflow.
  • Model dependent: requires device capability confirmation.
  • Unsupported: blocked for the detected family.

AOS 6 and AOS 8 are independent command families. Configuration-changing syntax is never sent experimentally for discovery. Explicit CLI rejection can be learned against exact device identity to prevent repeated incompatible attempts.

Selection still passes through authorization, parameter validation, scope, preview and Job creation.

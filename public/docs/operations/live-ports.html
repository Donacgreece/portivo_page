Operations

Live Port Inventory

Real-time interface state, logical port map and controlled port operations.

v2.0.0Source-backed

Live collection

Portivo can read administrative state, physical link, alias, VLAN, media and PoE evidence from a selected switch. The backend exposes live port collection through the switch workspace, subject to devices.live_ports permission.

Logical front panel

Supported models can render logical access, uplink and additional-interface groups. Device layout parsing is model-aware and intentionally rejects pseudo rows that are not physical front-panel interfaces.

Port Details

The Port Details view keeps current state, observed duration, configured/detected media, VLAN, PoE state and power evidence together. Controlled actions include alias changes, interface restart and PoE restart when permitted.

Observed duration

Portivo records latest state transitions rather than high-frequency time-series samples. Displayed duration therefore represents Portivo-observed state duration.

Source-backed detail

Collection and physical layout

Live Port Inventory runs on demand through the serialized device lane. It combines administrative and physical state, alias, VLAN, media and PoE evidence and caches the latest normalized result.

Logical front panels are model-aware. Multi-member stacks render separate chassis, while compact hardware uses exact SKU or unambiguous interface evidence to exclude non-physical summary rows. Unknown interfaces remain additional evidence instead of being forced into an incorrect slot.

Observed duration

Portivo stores the latest state and transition timestamp. Durations describe how long Portivo has observed that state; they are not historical telemetry from before the transition was seen.

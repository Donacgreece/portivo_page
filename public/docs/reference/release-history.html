Portivo 2.0.0 release notes

Public release notes for Portivo Control Center 2.0.0.

v2.0.0Source-backed

Open-source foundation

  • Portivo-owned source is licensed under AGPL-3.0-only.
  • Release packaging includes matching installer and source archives plus SHA-256 checksums.
  • SPDX SBOM, third-party notices and component license material are included.
  • In-application legal and source access is available.

Operations platform

  • Central inventory, live port operations, Find Device, Port Troubleshooter and governed command execution.
  • Nine Fleet Audits with normalized evidence and PDF reporting.
  • Jobs, activity history, explicit configuration persistence and bounded fleet execution.
  • Controlled Runbooks with COMMAND, WAIT and VERIFY steps, approval and scheduling.

Monitoring and power

  • Switch availability, stack-member health and incident confirmation.
  • SNMPv3 power monitoring with vendor-aware UPS drivers and protected-switch correlation.
  • Destination-scoped notification routing with delivery history.

Security baseline

  • Progressive authentication throttling and server-enforced capability/scope checks.
  • Session-only personal SSH credentials and encrypted unattended credentials.
  • Public API documentation disabled and public health metadata minimized.
  • WebSocket Origin validation, bounded imports and hardened webhook handling.
  • Verified Windows upstream artifacts and a hardened Linux systemd service profile.

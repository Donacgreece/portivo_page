CURRENT PRODUCT PLAN

Priority stages

This roadmap mirrors the plan shipped inside Portivo Control Center v2.0.0.

Releasedv2.0.0

Open Source Licensing & Distribution

  • AGPL-3.0-only with file-level SPDX attribution
  • Exact dependency locking, SPDX SBOM and third-party license inventory
  • Always-available license and exact-version source access
  • Clear contribution policy and reproducible release-asset contract
In progressActive

Reliability & data foundation

  • Switch capability matrix by model and AOS release
  • Automatic capability learning for unsupported commands
  • Maintenance mode and lightweight availability history
  • Safe concurrency controls for large fleets
NextPriority

Configuration safety

  • Automatic backup before persistent changes
  • Configuration versions and visual diff
  • Baselines and configuration drift detection
  • Controlled restore and rollback foundations
PlannedQueued

Operations intelligence

  • Port history and device event timelines
  • Smart incident correlation across repeated audits
  • Saved operational views and reusable workflows
  • Port profiles, change plans and approval workflows
ExploringResearch

Automation & integrations

  • Scheduled Fleet Audits with comparison policies
  • Notifications for new critical findings
  • Custom audit policy packs and baselines
  • Read-only REST API for internal integrations
No speculative dates. Priority stages communicate direction, not a delivery commitment.

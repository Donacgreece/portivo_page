CURRENT RELEASE

v2.1.0 revisions

The current release combines a new health architecture with supported uninstall and recovery workflows for Windows and Linux.

r6

Lowest-impact background reachability

Healthy switches receive one ICMP echo per normal poll. Failed probes get two bounded retries, then Auto may use one lightweight SNMPv3 request. TCP/22 probing is removed and fleet polling is spread with deterministic jitter.

r5

Windows uninstall encoding assurance

ASCII-safe wizard text and validation prevent PowerShell 5.1 mojibake without changing application behavior.

r4

Windows recovery and high-DPI reliability

Corrected the private-runtime import probe and kept uninstall actions visible across normal and high-DPI layouts.

r3

Branded cross-platform uninstall experience

Added a full Windows wizard and guided Linux workflow while retaining safe data-preservation and guarded-purge semantics.

r2

Supported uninstall and recovery lifecycle

Standard removal preserves environment, data and backups; full purge requires explicit confirmation and can create a final backup.

r1

Adaptive switch health architecture

Introduced ICMP-first reachability, optional independent SNMPv3 telemetry and configurable Auto, Ping or SNMPv3 health modes without background SSH authentication.
